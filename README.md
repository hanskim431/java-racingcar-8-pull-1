# java-racingcar-precourse 자동차 경주

## 기능 요구 사항
초간단 자동차 경주 게임을 구현한다.
- [ ] 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- [ ] 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- [ ] 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- [ ] 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
- [ ] 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- [ ] 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- [ ] 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- [ ] 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨 후 애플리케이션은 종료되어야 한다.

## 입출력 요구 사항
**입력**
- 경주할 자동차 이름(이름은 쉼표(,) 기준으로 구분)
```
pobi,woni,jun
```

- 시도할 횟수
```
5
```

**출력**
- 차수별 실행 결과
```
pobi : --
woni : ----
jun : ---
```
- 단독 우승자 안내 문구
```
최종 우승자 : pobi
```
- 공동 우승자 안내 문구
```
최종 우승자 : pobi, jun
```

**실행 결과 예시**
```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
5

실행 결과
pobi : -
woni : 
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

pobi : ----
woni : ---
jun : ----

pobi : -----
woni : ----
jun : -----

최종 우승자 : pobi, jun
```

## 상세 기능 요구 사항

### 1. 입력 처리
- [x] 자동차 이름 입력받기
  - [x] "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)" 메시지 출력
  - [x] 사용자 입력을 쉼표(,)로 분리하여 자동차 이름 리스트 생성
  - [x] 각 이름의 앞뒤 공백 제거 처리

- [ ] 시도 횟수 입력받기
  - [x] "시도할 횟수는 몇 회인가요?" 메시지 출력
  - [ ] 입력값을 정수로 변환

### 2. 입력 검증
- [ ] 자동차 이름 검증
  - [x] 각 자동차 이름이 5자 이하인지 확인
  - [x] 5자를 초과하면 `IllegalArgumentException` 발생
  - [x] 빈 문자열 이름이 있는지 확인 (있으면 예외 발생)
  - [ ] 중복된 이름이 있는지 확인 (선택적 요구사항)

- [ ] 시도 횟수 검증
  - [ ] 입력값이 숫자인지 확인
  - [ ] 숫자가 아니면 `IllegalArgumentException` 발생
  - [x] 양수인지 확인 (0 이하면 예외 발생)

### 3. 자동차 객체 생성
- [x] Car 클래스 구현
  - [x] 이름(name) 필드
  - [x] 위치(position) 필드 (초기값 0)
  - [x] 전진(move) 메서드: 조건 만족 시 position 1 증가
  - [x] 현재 위치 반환 메서드

### 4. 무작위 값 생성
- [ ] 0~9 사이의 무작위 정수 생성
- [ ] camp.nextstep.edu.missionutils.Randoms 활용
  - [ ] `Randoms.pickNumberInRange(0, 9)` 사용

### 5. 이동 로직
- [ ] 각 라운드마다 모든 자동차에 대해:
  - [ ] 무작위 값 생성
  - [ ] 값이 4 이상이면 해당 자동차 전진
  - [ ] 값이 4 미만이면 정지 (위치 변화 없음)

### 6. 경주 진행
- [ ] RacingGame 클래스 구현
  - [ ] 자동차 리스트 관리
  - [ ] 지정된 횟수만큼 라운드 반복
  - [ ] 각 라운드 종료 후 결과 출력

### 7. 출력 처리
- [x] 실행 결과 출력
  - [x] "실행 결과" 메시지 출력 (첫 라운드 전)
  - [x] 빈 줄 추가 (메시지와 결과 사이)

- [x] 각 라운드 결과 출력
  - [x] 각 자동차별로 "{이름} : {위치}" 형식으로 출력
  - [x] 위치는 "-" 문자로 표현 (position 값만큼 반복)
  - [x] 전진하지 않은 경우 이름과 콜론만 출력 (예: "woni : ")
  - [x] 각 라운드 후 빈 줄 추가

- [x] 우승자 출력
  - [x] 가장 많이 전진한 자동차(들) 찾기
  - [x] "최종 우승자 : {이름}" 형식으로 출력
  - [x] 공동 우승자는 쉼표와 공백(", ")으로 구분

### 8. 우승자 결정
- [ ] 모든 자동차의 최종 위치 비교
- [ ] 최대 위치값 찾기
- [ ] 최대 위치값을 가진 모든 자동차를 우승자로 선정
- [ ] 우승자가 여러 명인 경우 처리
